# Personal Portfolio — Samarth Ahuja

A responsive personal portfolio built to showcase my skills, projects and frontend development journey.

**Live Demo:** https://invoqepersonalportfolio.vercel.app

## Tech Stack
- React.js
- Tailwind CSS
- JavaScript
- Vite

## Features
- Responsive design
- About Me and Skills sections
- Project cards with GitHub and Live Demo links
- Contact and social links
- Dark theme

## Run Locally
```bash
npm install
npm run dev
```
