## Run Locally

To run this project on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/samarthahuja827/Invoqe_PersonalPortfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Invoqe_PersonalPortfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
